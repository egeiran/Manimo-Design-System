# Brand assets

| File | Purpose |
|---|---|
| `manimo-mark.svg` | Standalone mark — a smooth curve through three dots. Use as favicon, app icon, splash mark, video watermark. |
| `manimo-wordmark.svg` | Full lockup — mark + wordmark. Use for top bar, marketing, signatures. |

The curve gradient runs warm amber → rose. The third dot (right side) is teal — a tiny color cue that ties the mark to the data/code accent.

**Clear space.** Leave at least the height of the mark on all sides.
**Minimum size.** Mark: 24px. Wordmark: 96px wide.
**Don't.** Recolor it. Stretch it. Stack the wordmark vertically. Add a drop shadow.
